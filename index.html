🔄 How to Update Your Dashboard on GitHub

1 Add a New Client Using the Dashboard

→
Use the "Add New Client" button
Click the Clients icon in the sidebar → click the blue + Add New Client button at the top right → fill in the form → click Save. The client appears instantly in your dashboard.
!
But this is only saved in your browser session!
When you refresh the page or open it on another device, the new client disappears. To make it permanent, you need to save it to GitHub. Follow the steps below.

2 Copy the Updated Client Data Block

1
After adding your client, click "Copy Data Block" button
After saving a client in the Add Client form, a green "Copy Data for GitHub" button appears. Click it — the correctly formatted JavaScript object is now in your clipboard.
2
What the copied text looks like
// Paste this inside the CLIENTS array in index.html
{opid:"NEWCLIENT", status:"Active",
 product:"CNMS Onnet", productType:"Standard",
 sheet:"NEW", onboardingDate:"2026-04-22",
 rate:1.5, monthlyBill:885, ...},

3 Edit index.html on GitHub

1
Open your repository on GitHub
Go to github.com/YOUR-USERNAME/intellidata-dashboard
2
Click on index.html → then click the pencil ✏️ icon
This opens the file editor directly in your browser. No software needed.
3
Find the CLIENTS array using Ctrl+F (Cmd+F on Mac)
Search for the text: const CLIENTS = [
Scroll down to find the last entry in the array (it ends with a } before the closing ];)
// Find this section — add your new client just before the ];
  {opid:"CITYNET", ...},
  ← PASTE YOUR NEW CLIENT ENTRY HERE
]; // <-- end of array
4
Paste your copied data here, then click "Commit changes"
Scroll to the bottom of the GitHub editor → click the green Commit changes button → your live site updates in about 60 seconds!
💡 Make sure the previous entry has a comma , at the end before your paste. Example: ...}, ← comma here

4 Quick Reference — Client Data Fields

{
  opid: "ABCDE",             // Client ID (required)
  status: "Active",         // "Active" | "Under-Deployment" | "Blocked"
  product: "CNMS Onnet",    // "CNMS Onnet" | "NetManazer" | "IPTV"
  plan: "Standard",        // "Standard" | "Pro"
  sheet: "NEW",            // "NEW" | "ReActivation" | "NetManazer"
  onboardingDate: "2026-04-22", // YYYY-MM-DD format
  billingEffective: "2026-04-22", // or null if not yet
  rate: 1.5,                // ₹ per SMS
  minBilling: 500,        // minimum messages
  period: 12,              // months
  salesDeal: "1.5×500×12+Tax",
  freeSMS: "2 (WA)",       // or null
  baseAmount: 750,
  tax: 135,                // 18% GST
  monthlyBill: 885        // base + tax
},
